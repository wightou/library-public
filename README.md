# Competitive Programming Library

競技プログラミング用の個人ライブラリです。

## Environment

- Language: C++23
- 主な用途: AtCoder などの競技プログラミング

## AI Assistance

本ライブラリは自筆ベースですが、その一部は、生成AIによるコードレビュー、バグの指摘、アルゴリズムや実装方針の検討などの支援を受けて作成されています。\
ライブラリ以外の部分は、AIが全て作成していることもあります。
